# Mariah Carey wallpaper

**[在线体验 →](https://lambily555.github.io/Mariah-Carey-wallpaper/)**

[![Mariah Carey 香槟金动态壁纸预览](docs/preview.png)](https://lambily555.github.io/Mariah-Carey-wallpaper/)

以香槟金为主的动态壁纸，包含人物渐显、环绕丝带、蝴蝶扇翅、星光与歌词短句。提供浅香槟、红金、紫金、蓝金及多组撞色，共十二套配色；配色同时作用于背景、丝带与粒子。

## 使用

下载仓库后，用桌面浏览器打开 `index.html`。无需安装依赖。

- **R**：重播入场动画
- **H**：隐藏或显示界面，查看纯壁纸
- **F**：全屏
- 右上角展示五个配色圆点，点击「···」展开其余配色；点击空白处或按 Esc 收起。默认展示「浅香槟」
- 歌词两侧箭头切换歌曲，小「＋」批量导入自己持有的 TXT / LRC 文件，可选择整首循环或指定连续两句，并为背景设置另一首歌的片段；每天自动更换歌曲

滚动区内置《Butterfly》和《4real4real》的简短节选，背景使用《All My Life》的简短节选；不包含完整歌词或音频。导入内容仅保存在当前浏览器。

这是独立网页，尚未集成到 Codex 客户端。已适配系统的减少动态效果设置。
